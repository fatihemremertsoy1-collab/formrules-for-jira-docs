Quick Start Guide

  1. Open FormRules: Go to Jira Settings → Apps → FormRules - Dynamic Field Rules (Global Admins) or Project Settings → FormRules - Field Rules (Project Admins).
  2. Choose Context & Screens: Select your Jira Project, Issue Type, and check one or more screens (Create Screen, Issue View, Transition, JSM Agent).
  3. Define IF Conditions: Branch on any Jira field, Current User's Jira Group, or Current User's Role using ALL (AND) or ANY (OR) logic, with live Quick-Pick value suggestions.
  4. Define THEN Actions: Combine Hide/Show, Require/Optional, Lock Read-Only, Rich ADF Description Templates, Dropdown Option Filtering, or Dynamic Label Renaming.
  5. Simulate & Activate: Verify rule interactions in the Rule Simulator tab, or test immediately on your Jira screens.

Platform Compatibility Notes

  • Dynamic Label Renaming: Jira Cloud renders dynamic field label changes on the Create Issue screen; Issue Detail View retains standard labels while enforcing visibility, required, read-only, and template rules.
  • 100% Runs on Atlassian: Zero outbound network calls. All rule configurations and version history remain strictly inside your Atlassian Cloud tenant.
