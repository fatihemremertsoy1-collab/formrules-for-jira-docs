Privacy Policy

Effective Date: November 25, 2026 · App: FormRules for Jira (Atlassian Forge)

Summary: FormRules for Jira is built 100% on Atlassian Forge (Runs on Atlassian) with zero external egress. No Jira issue content, personal data, or rule configurations are ever transmitted to or stored on external servers controlled by the developer.

1. Data We Access and Process

FormRules for Jira operates entirely within your Atlassian Cloud tenant and accesses only the minimum Jira metadata required to configure and evaluate field rules:

  • Jira Configuration Metadata: Project IDs/keys, issue types, field definitions, and priority lists (read via read:jira-work and manage:jira-configuration) solely to populate the rule builder interface.
  • User Permission Check: Current user permission status (via read:jira-user and Jira's mypermissions API) to verify that only authorized Jira Administrators or Project Administrators can modify rules.
  • In-Browser Field Evaluation: When end users open a Create, View, or Transition screen, rule evaluation runs inside the user's browser via Atlassian's sandboxed jira:uiModifications Custom UI bridge. Issue field values are evaluated transiently in memory and are never logged or sent outside Jira.

2. Data Storage & Hosting

  • Active Rules: Stored natively inside your Jira Cloud site using Atlassian's UI Modifications API (/rest/api/3/uiModifications).
  • Version History Snapshots: Stored inside Atlassian Forge Hosted Key-Value Storage (storage:app), partitioned per Jira Cloud installation, encrypted at rest and in transit by Atlassian, and subject to Atlassian Cloud's data residency controls.
  • No External Servers or Subprocessors: FormRules for Jira has no external backend, no third-party analytics trackers, and no external subprocessors.

3. Data Retention & Deletion

Rule configurations and up to 25 recent history snapshots are retained only while the app is installed on your Jira Cloud site. Administrators may delete individual rules at any time from the FormRules interface. When FormRules for Jira is uninstalled from your Jira site, Atlassian automatically purges Forge hosted storage and app-managed UI Modifications in accordance with Atlassian Forge's lifecycle retention schedule.

4. Security & Incident Notification

Because the application runs exclusively on Atlassian Forge with zero egress domains configured in manifest.yml, network exfiltration is blocked at the platform level by Atlassian. In the unlikely event of a confirmed security vulnerability affecting the app, we will notify affected customers via Atlassian Marketplace security channels and email within 24 hours of confirmation.

5. GDPR, CCPA & Your Rights

Because FormRules does not collect, sell, or export personal data to external systems, all data subject rights (access, correction, deletion) remain directly under your Jira administrator's control within Atlassian Cloud.
